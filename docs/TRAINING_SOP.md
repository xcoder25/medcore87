# Training SOPs — pilot hospital

## Reception
1. Log in with enrolled badge + PIN.
2. Register new patient (or search State Health ID / existing MRN).
3. Print/issue digital card; route to triage or clinic queue.
4. Never share badge PIN.

## Clinical (doctor / nurse)
1. Open **Dashboard** → work from **shared queue** (shift continuity).
2. Open chart → document → order labs/Rx via suite modules.
3. Handover: leave clear note on chart; next shift uses same patient record.

## Pharmacy / Lab
1. Work from pending orders queue.
2. Dispense / result → system LIVE events notify clinical staff when API WS is up.

## Billing / cashier
1. Charge against encounter; take payment; receipt.
2. HMO: eligibility then claim path when configured.

## Admin
1. First login → complete onboarding (one admin per hospital).
2. Enrol staff only; one hospital_admin per facility.
3. System Administration: backups and service health.
4. Statewide HIE module for MPI/SHR when cross-facility care needed.

## Attendance
- Staff walk past camera; AI posts punch; **no video stored** in MedCore.
